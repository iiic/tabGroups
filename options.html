Tab Groups settings

The easier way to turn a module off is “Advanced module settings” → “Module activation mode” → “Never start (module inactive)”. The module stays in its place in the list and you turn it back on with a single switch.

Removing it from the list saves more performance, though: the content script of a turned-off module is still inserted into every page (and only there finds out it has nothing to do), and the side panel, the floating window and Settings still load its file. A module that is not in the list is not loaded at all. The difference shows mainly with modules that work in pages.

A module uploaded from a file runs in an isolated page (sandbox).
